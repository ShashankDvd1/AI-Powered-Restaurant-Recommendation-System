# AI-Powered-Restaurant-Recommendation-System
Building an AI-powered restaurant recommendation service inspired by Zomato. The system should intelligently suggest restaurants based on user preferences by combining structured data with a Large Language Model (LLM).

# Objective #
1. Design and implement an application that:
2. Takes user preferences (such as location, budget, cuisine, and ratings)
3. Uses a real-world dataset of restaurants
4. Leverages an LLM to generate personalized, human-like recommendations
5. Displays clear and useful results to the user
